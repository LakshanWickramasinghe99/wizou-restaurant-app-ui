# 🍕 WIZOU - Gourmet Restaurant Mobile App UI/UX Design

A modern, clean, and intuitive mobile application UI/UX concept designed for **WIZOU Restaurant**. Built with a mobile-first approach emphasizing high visual appeal, seamless navigation, and frictionless ordering UX.

## ✨ Key Features & UX Highlights

* **Brand Identity & Splash:** Minimalist luxury aesthetics featuring gold and dark navy color tones.
* **Smart Home Experience:** Instant delivery type toggles (Delivery/Takeaway/Dine-in), dynamic hero banner, and clear food category navigation.
* **Interactive Menu & Filtering:** Dietary indicators (Veg/Non-Veg), quick-add buttons, ratings, and active floating cart notifications.
* **Frictionless Checkout:** Interactive add-ons, coupon code savings calculator, and a clear bill breakdown.
